## A trial copy is live

**https://termtrail.com** (Phase 66, 15 November 2026; it began as `https://amsima.com/termtrail`, Phase 52, which now sends every page on to the new address) runs this branch on the owner's Mac mini, for his partner to review. Sign-in is Google (since 15 November 2026), and only for the test users listed in the owner's Google Cloud project "Termtrail", which is in Testing: that keeps the trial private. The access-code sign-in it started with is off (its settings are still in the host's file, and it returns if the Google client is removed). It has no AI key, so the AI features say they are not set up. Checked from the public internet: the page, manifest and service worker load, the old address redirects, and "Sign in with Google", clicked in a browser where the offline worker was already installed, reaches Google's account chooser for termtrail.com (the worker used to swallow that click; fixed the same day). The owner then signed in with his Google account in a browser (15 November 2026). How it is hosted and updated: `DEPLOY_SUBPATH.md`.

Because it is a real HTTPS site, the phone checks listed under "Needs a device or a person" can now be done on it by anyone holding a phone and the access code: add to Home Screen, notifications, touch and Pencil, the share sheet, and the lecture-collector bookmark.
